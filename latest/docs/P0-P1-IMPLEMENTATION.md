## 验证证据

- 最终安装包的 94 项自动检查全部通过，其中本轮新增 48 项检查。
- 安装包 STDIO 验证通过：版本和构建正确，248 项注册，3 项重新开放工具可检索；之前移除的 5 项工具搜索与调用均被拒绝。
- 最终安装包通过独立 COM MCP 进程实际调用三项重新开放工具，确认 248 项全部启用；完成检查、保存重开和 DWG/PDF 交付。
- 导出 DWG 通过独立 ObjectDBX 读取核验：20 个实体、16 个关联引用有效。修复了整库复制后句柄变化造成的轴网关联失效。
- 米制房间实测面积 76.44 平方米；组合建图房间实测面积 18.24 平方米。
- 门窗明细扩行后各行高度 350、文字高度 125，与设定一致。表格尺寸变化时重建表格以保持排版。
- 失败分支验证包括：过期预览拒绝执行、原生事务回滚、检查未通过不输出、已有文件不覆盖、失败交付恢复、旧记录单位不明时拒绝写入。

## 使用范围

- 新增修改工具先预览，确认凭证同时绑定当前图纸快照和操作参数；图纸或参数变化后需重新预览。新增原生编辑使用事务，既有生成器沿用各自撤销机制。
- 原生快照上限为 200000 个实体。达到读取限制时明确报告完整性，不能把未读取部分视为检查通过。
- 门窗整理从带属性的块开始，需要用户指定字段映射。散线门窗的语义识别尚待后续扩展。
- 面积计算采用用户提供的项目规则；不同面积类型分别统计。停车位尺寸和通道参数由项目确定，车辆转弯轨迹属于后续需求。
- 封闭梁轮廓裁切当前针对多边形柱；复杂曲面与三维连接需另行处理。
- 楼梯净高检查需要可靠的剖面数据。资料不足时返回待补充内容。
- 明细表尺寸变化可能更换实体句柄，调用结果提供新关联。
- 交付列出外参、字体和打印样式，当前不自动打包这些资源。移动交付图纸后应核对相对外参路径。
