# 图纸碎数整理

版本：1.6.0.post2 · 构建：precision-20261127.1 · 验证日期：2026-11-27。

## 用途

整理墙线中接近整数的零碎坐标。例如水平线实际长度为2999.997 mm，按1 mm网格整理后变为3000 mm；与它共用端点的墙线一起调整，保持墙角连接。

工具名：`drawing_round_geometry`。支持中文搜索“碎数”“碎数整理”“坐标取整”。

## 使用方法

1. 明确选择要处理的实体，并核对图纸实际单位和项目网格基点。
2. 指定网格步长及单点最大位移，调用默认预览。
3. 检查`changes`中的坐标、段长和最大位移，以及`skipped`和`blockers`。
4. `can_apply=true`时，以相同参数、`dry_run=false`和本次`preview_token`执行。
5. 查看`applied_count`和`readback_verified`，再检查相关尺寸与填充。

示例预览参数：

```json
{
  "handles": ["A1", "A2"],
  "step_mm": 1,
  "max_move_mm": 0.01,
  "origin": [0, 0],
  "dry_run": true
}
```

句柄需替换为当前模型中实际对象。`origin`为WCS坐标，采用图纸单位；应填写项目使用的网格基点。步长和位移上限统一采用毫米。`model_units`可在已核对实际单位后显式指定为`mm/cm/m/inch/ft`；省略时读取INSUNITS。

位移上限必须大于0且不超过网格步长的一半。工具按XY坐标归整；沿水平/垂直方向的线段长度随实际端点变化。Z坐标、句柄、图层和多段线闭合状态保持原值。

## 适用范围与保护

- AutoCAD 2026 COM后端，模型选项卡；依赖现有CadMcpProjectFix2026桥，本次无新增或替换DLL。
- 支持LINE和法向+Z、零宽、无圆弧段的轻量多段线；整理后的线段应为水平或垂直。
- 每次1–100个实体、最多500个待修改直线段；单个多段线最多200个顶点。
- 模型快照上限50000个对象，邻近COM详细读取上限500个对象。对象多时建议缩小选择范围；快照缺失或无法完整检查时停止。
- 锁层、斜线、圆弧、宽多段线、块、外参、带厚度或扩展字典的对象列入跳过项。附近存在无法检查的对象时，会阻止执行。
- 同高线段的端点搭接、T形接点及交叉关系在修改前后进行比较；未选中的邻近实体保持原坐标。
- 位移超限、零长度段、闭合区域塌缩或连接关系改变时，整次拒绝写入。
- 预览token与当前服务、图纸、单位、参数及几何快照绑定。执行后或图纸变化后，需要重新预览。
- 每批操作设置撤销标记，并逐对象读回。写入失败时尝试恢复原坐标，返回恢复核验结果。出现超时应先查看CAD当前状态。
- 尺寸、填充、几何约束和建筑工具元数据需单独核对；工具不会自动保存图纸。
