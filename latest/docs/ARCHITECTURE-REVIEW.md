# 建筑设计能力评估与工具清单

2026-11-27。评估基准为86a75d6中的240项注册工具，包括3项禁用工具。

## 结论

CAD-MCP已覆盖建筑二维制图的大部分基础操作：实体编辑、图层、尺寸、文字、图块、图框、视口和输出；具备墙门窗、楼梯、正交轴网、轴号和房间的基础生成能力。完整建筑工作流仍缺少既有图纸的构件关联、停车排布、面积口径计算、建筑专项检查和稳定的综合交付流程。

本轮删除5项面向机械制造或工厂工艺图的入口，保留232项启用工具和3项禁用工具，合计235项注册。建筑节点会使用的焊接符号、材料填充、圆心定位、部品编号及块属性清单继续保留。

本次逐项检查240项工具的用途、完整参数和限制，对专用工具和边界项进一步核对实现；另检查注册、搜索和调用拒绝状态。此处的“保留”说明建筑用途成立，具体对象和参数仍应按工具说明使用。本轮未在项目图上重跑所有写入分支。

## 已删除的入口

|工具|原因|
|---|---|
|`mech_hole_pattern`|面向机械钻孔、节圆及孔径标注；建筑圆形阵列继续由通用实体阵列完成。|
|`std_feature_draw`|绘制螺纹、退刀槽、挡圈槽、中心孔和O形圈槽，属于机械零件制造。|
|`std_part_list`|原目录面向ISO紧固件和轴承规格；从建筑产品入口移除机械标准件目录。建筑节点配件继续使用项目块库。|
|`std_part_insert`|与机械标准件目录配套，含轴承及机械零件视图；建筑节点保留通用块插入与属性维护。|
|`drawing_scale_check`|实际匹配工厂设备位号，比较工艺图与布置图比例；建筑单位校核由drawing_unit_context承担。|

上述入口的函数声明及搜索别名已移除。建筑工具仍使用原工程库中的基础几何、块属性和图框函数，共享代码按依赖保留。机械标准件若后续纳入建筑节点库，应按实际建筑连接件需求重新组织。

## 三项禁用功能

|工具|建筑用途与处理意见|
|---|---|
|`validation_check`|建筑相关，保留禁用。duplicate_entities参数有声明但函数没有实现分支；固定读取上限且不报告完整性；零长判断使用XY和固定容差。应分页、落实检查项并分离执行状态与问题状态。|
|`drawing_finalize`|建筑相关，保留禁用。先保存/截图再校验，存在失败时已输出的情况；校验器含机械图层和齿轮预期。应改为建筑检查预览→确认→保存输出。|
|`drawing_deliver`|建筑交付相关，保留禁用。始终追加DXF，格式未覆盖DWG；沿用综合评分门槛。应按DWG/PDF需求重建交付清单、可恢复导出与逐项核验。|

三项均继续禁用。先完善基础检查，再重建完成检查和交付流程；本轮不把未完成的修复列为可用功能。

|P2|家具/客房批量布置|有家具洁具插入；缺房间方向、门窗避让、通道净距和批量房型规则|furniture_layout：先支持明确房型和标准组合，复杂空间由用户确认。可行性中等|

|P2|车辆转弯与扫掠|当前未覆盖|与停车排布分开规划，需车辆参数和轨迹模型，或对接可用的专业软件。实现及验收成本较高|
