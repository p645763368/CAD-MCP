# CAD-MCP 顶部状态栏

版本：1.6.0.post3，构建：status-20261127.1。

## 使用

AutoCAD顶部新增CAD-MCP页签，标题显示“已连接”“未连接”或“已暂停”。打开页签后可查看连接状态、接入开关和最近两条调用。

|显示项|含义|
|---|---|
|MCP服务|已收到该服务进程的状态更新；可同时显示多个服务|
|客户端|STDIO客户端已完成初始化握手；连接关闭后服务退出，界面随心跳过期更新|
|AutoCAD|该服务的COM后端连接到当前CAD进程|
|接入开关|允许或暂停后续工具操作；暂停后仍允许状态检查及工具检索|
|同步中|界面开关已改变，服务正在接收新状态|
|执行中|工具调用已经开始；暂停接入会让它继续完成|
|待核对|操作执行期间服务心跳中断，需要检查CAD里的实际结果|

状态每秒更新，约5秒未收到更新后显示未连接。主要面向本地STDIO客户端；HTTP连接的握手不计入STDIO连接数量。

点击“查看调用历史”可查看最近200条：时间、工具名称、结果、耗时、服务PID和异常类型。历史窗口为可停靠面板。检索及代理入口不重复记账，实际工具调用单独记录。

命令：

- `CADMCPSTATUS`：显示并切换到CAD-MCP页签。
- `CADMCPHISTORY`：打开调用历史。
- `CADMCPHIDE`：隐藏页签和历史窗口，服务继续运行。

恢复界面可执行`CADMCPSTATUS`。暂停状态在当前CAD会话内保留，MCP重启后仍从CAD读取开关；重启CAD后默认开启接入。

## 安装与通信

新增`CadMcpStatus2026.bundle`，包含状态栏DLL和AutoCAD 2026启动加载清单。普通安装使用当前用户ApplicationPlugins目录；已有三个几何桥模块保持原样。本次状态栏扩展不增加MCP业务工具数量，仍为240项注册、237项启用。

Python服务与CAD界面通过当前用户专用的本机命名管道交换状态。管道按用户SID和CAD进程ID区分，只允许当前Windows用户连接。界面通信在后台进行，不占用CAD绘图线程等待服务。

Python端的单次通信有超时，状态栏缺席时仍可使用原有MCP工具。已收到的暂停指令会保留，直到CAD端确认恢复。无界面ezdxf测试不连接CAD状态栏。

历史仅驻留内存，最多保留8个服务会话的摘要，并在界面显示最新200条；不写日志文件，不收集图纸路径、实体内容、调用参数或返回数据。MCP原有日志策略保持原样。

加载后页面与控制属于正式功能，保留供日常使用；测试中的开关和窗口状态在验证后恢复。
