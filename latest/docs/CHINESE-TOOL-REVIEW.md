## 范围与结论

对当前注册的 **248 项工具、1015 个顶层参数**进行了完整目录扫描，核对搜索摘要、完整描述、参数说明和风险标记。对发现的单位、范围、前置条件及副作用问题追溯 Python 包装层、后端实现和原生桥代码。

## 重点修正

|问题|修正后的含义|
|---|---|
|双排车位描述为背靠背|车位位于中间通道两侧；明确候选数、起点、方向和双侧覆盖规则。|
|停车排布易被理解为自动优化场地|用户指定停车行方案，工具过滤边界、障碍和通道冲突；未搜索最优排布，通道参与计算但不绘制通道线。|
|门窗表更新风险偏低|行列数或比例改变时删除重建表格，风险改为destructive；句柄可能变化。|
|门窗编号、门窗表、建筑记录表混淆|door_window_tag关联属性块；schedule_update生成/更新属性块数量表；arch_schedule读取已有ACADMCP_ARCH记录。|
|门窗属性修改后的更新方式不明确|显式调用才更新；同号异规格拒绝，需重新编号；没有后台自动监听。|
|建筑尺寸链偏移写为图纸单位|first_offset和step实际使用毫米；比例为出图分母。|
|视口数值比例与物理比例混淆|原始scale只表示纸/模型数值比；跨单位的1:100使用scale_denominator。|
|通用参数文案污染语义|明确房间name为用户名称、洞口offset为沿墙距离、system变量name为变量名；拆开语言与比例说明。|
|房间识别范围过宽|说明直线/直线段多段线、600毫米狭长过滤、散线门洞未封闭可能合并、skipped/omitted；识别不写房间名称。|
|检查通过易被理解为零问题|ok执行、passed无error、complete读取完整；重合几何是warning，默认passed仍可为true。|
|交付严格检查含义不明确|strict_critique只控制validation_check警告是否阻断；不调用drawing_critique。|
|面积重叠约束不完整|同楼层且同面积类型才禁止区域重叠；不同面积类型分别汇总。|
|预览与执行前置条件遗漏|补齐模型空间、dry_run、expected_token及不自动保存的说明。|
|旧工具推荐残留|移除剖切工具中对已删除mech_view_add的推荐；区分定位符号与剖面生成。|
|曲线、拉伸、图层合并描述遗漏分支|明确分割保留源对象开关、完全框入对象移动选项、块定义处理开关及偏移仅保留首个结果。|
