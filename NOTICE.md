# Attribution and scope

This repository contains a locally modified snapshot of **AutoCAD MCP Pro
1.6.0**, originally by **Umutcan Edizsalan**:
https://github.com/U-C4N/Autocad-MCP

The original MIT license and copyright notice are preserved in LICENSE and
latest/metadata/licenses. This is a customized snapshot, not an official
upstream release.

The included CadMcpNative2026, CadMcpArch2026V2Safe and CadMcpProjectFix2026 DLLs
are the custom bridges maintained with the matching C# source in this repository.
Autodesk application/SDK DLLs are referenced for compilation and are not bundled.
An appropriately installed/licensed AutoCAD remains required.

Generic template resources under latest/python/templates belong to the base
distribution. Business DWG files, company templates, project calculations,
screenshots, local settings, migration backups and test exports are excluded.
